# Як завершити перевірку перед поданням

1. Відкрийте папку у VS Code.
2. Виконайте `npm install`.
3. Виконайте `npm test`, `npm run coverage`, `npm run lint`, `npm run format:check`.
4. Якщо форматування не пройшло, виконайте `npm run format`, потім повторіть перевірку.
5. Зробіть скриншот фактичного звіту coverage і додайте до звіту.
6. Перегляньте `git log --oneline --reverse`.
7. Запуште проєкт у власний GitHub-репозиторій і додайте посилання до звіту.
8. Рецензію на однокурсника заповніть за його реальним репозиторієм.

Примітка: під час підготовки npm install завершився тайм-аутом, тому результати тестів і coverage не позначені як фактично підтверджені.
