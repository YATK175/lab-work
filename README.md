# Лабораторна робота №3 — TDD, варіант 4

## Завдання

Тарифікатор таксі:

- посадка — 40 грн;
- перші 3 км включені у вартість посадки;
- понад 3 км — 12 грн за кожен кілометр (для дробової відстані тариф пропорційний частці кілометра);
- нічна надбавка — 25% до базової вартості;
- мінімальна базова вартість поїздки — 80 грн.

Вхідна відстань має бути скінченним невід'ємним числом. Нічна надбавка застосовується після визначення мінімальної базової вартості; результат округлюється до двох знаків після коми.

## Запуск

```bash
npm install
npm test
npm run coverage
npm run lint
npm run format:check
```

## TDD

Історія Git містить окремі коміти для кроків Red/Green і щонайменше два коміти Refactor. Для перегляду:

```bash
git log --oneline --reverse
```
